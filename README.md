# 血源诅咒 PC 中文增强版

这里公开我们在 bbport 基础上修改的 PC 引擎源码和便携启动代码。主要做了中文界面、直接启动、画面增强，以及更适合电脑游玩的操作和菜单。

经作者测试，游戏流程稳定运行 60 帧。实际帧率受显卡、分辨率和画质设置影响。

## 我们改了什么

- **中文化**：启动前确认、PC 设置、键位说明和操作指引使用中文，支持中文目录。
- **直接启动**：双击游戏入口即可进入，不用再打开旧启动器。首次启动先检测硬件，再选择键鼠或手柄。
- **每次启动提示**：先显示免费项目说明，确认后才检测硬件，再选择键鼠或手柄；取消或关闭即退出。说明包含作者灰灰（呆呆）、群号 721775768 和项目地址，没有“不再提醒”选项。
- **更新进度**：关注抖音 43396406929，或 B 站“水生郁”，获取最快更新进度。谢谢大家！
- **画面增强**：加入硬件光追环境遮蔽和接触阴影，提供独立开关、强度、范围和采样设置。
- **超分与神经增强**：接入 DLSS、FSR 3.1、FSR 4 和 FSR 4.1.1；提供神经增强、锐化和画质设置。菜单中“DLSS 5”为本分支功能名称，具体实现以源码和所用运行库为准。
- **显卡适配**：启动时识别显卡、驱动和显存，为 AMD 与 NVIDIA 设置不同的默认配置，修复 FSR 切换和画面偏色问题。
- **键鼠操作**：支持鼠标镜头、锁定、射击、重击、武器切换、道具切换和自定义键位。
- **手柄操作**：支持 Xbox／PlayStation 提示、设备配置、断线重连；默认 L1／LB 单键格挡，L3 武器变形，也能切回组合操作。
- **锯齿砍刀格挡**：加入格挡、受击、收刀和破防动作，以及精力消耗、减伤和完美格挡窗口。
- **游戏内菜单**：加入狩猎手记、手动保存、返回主界面、镜头灵敏度和画面设置。
- **小地图与操作指引**：支持道路、墙体、角色和附近标记；F2 切换透明操作指引，F3 更改操作方式。
- **屏幕适配**：自动读取屏幕分辨率，支持无边框全屏、F11 切换和界面等比缩放。

光追和部分增强功能取决于显卡能力；AMD 默认关闭本分支的实验性光追和 DLSS 神经增强。4K 输出可使用超分重建。

## 源码目录

- `src/`：运行时、音频、文件、输入和存档相关实现。
- `gpu/`：Vulkan 渲染、超分、光追、中文菜单及游戏内操作。
- `tools/`：构建工具、硬件检测和菜单工具。
- `portable/engine/`：当前便携版使用的启动及硬件配置代码。
- `scripts/`、`tests/`：准备脚本与现有检查程序。
- `licenses/`、各第三方目录：原有授权说明。

构建步骤及依赖说明见 [上游说明](README.upstream.md)。本次发布为修改后的源码快照，未宣称已在全新环境完成构建验收。部分构建、准备脚本需要用户自行提供游戏文件、运行库或补丁数据。

Windows 构建还会生成 `out/bloodborne-entry.exe` 和 `out/bb-startup-notice.dll`。便携安装时，将前者命名为游戏根目录的“血源诅咒.exe”，后者放入 `engine/`，并同步更新 `engine/portable_game.py` 和 `engine/bb-probe.exe`。

提示文本编译在 `src/startup_notice.h` 中，原生入口和引擎入口都执行检查；直接运行便携脚本也必须完成确认。确认只在本次启动有效，关闭程序后失效。这是启动流程检查，不是防篡改技术，有源码或修改权限的人仍可更改它。
